# Личная библиотека (PyQt5 Application)

Десктопное приложение для каталогизации и удобного управления личной коллекцией книг с графическим интерфейсом на PyQt5 и реляционной базой данных SQLite.

---

## Описание проекта и функционал

Программа предназначена для систематизации личной библиотеки пользователя, ведения учета прочитанных книг и их характеристик.

### Реализованные возможности:
1. **Каталог книг:** Отображение списка книг в виде интерактивной таблицы с колонками: ID, Название, Автор, Год издания, Жанр.
2. **Полный цикл управления записями (CRUD):** 
   - **Добавление:** вызов модального диалогового окна с заполнением полей.
   - **Редактирование:** изменение любой информации о выбранной книге.
   - **Удаление:** стирание записи из базы данных с подтверждением через системный диалог.
3. **Мультимедийные функции:**
   - Отображение графических обложек (JPG, PNG). Реализован автоматический разворот фото по метаданным EXIF с помощью `QImageReader`.
   - Звуковое оповещение через `QMediaPlayer` при подтверждении операции удаления книги.
4. **Надежная валидация входных данных:**
   - Защита от создания записей с пустым названием или автором.
   - Динамическое ограничение года выпуска: значение не может быть отрицательным и автоматически сверяется с текущим системным годом (работает корректно в любом году).
5. **Работа с СУБД:** Использование SQLite с архитектурой из 2 связанных внешним ключом таблиц (`genres` и `books`).

---

## 🛠 Стек технологий

- **Язык разработки:** Python 3.10+
- **GUI Фреймворк:** PyQt5 (архитектура форм спроектирована по стандартам QtDesigner)
- **База данных:** SQLite3 (встроенный модуль, прямое управление транзакциями)
- **Мультимедиа:** Модули `PyQt5.QtMultimedia` и `PyQt5.QtGui`
- **Компиляция в бинарный файл:** PyInstaller

## Установка и запуск из исходников

### 1. Клонирование репозитория
Клонируйте проект с GitHub и перейдите в рабочую директорию:
```bash
git clone https://github.com/МОЙ_НИКНЕЙМ/МОЙ_РЕПОЗИТОРИЙ.git
cd МОЙ_РЕПОЗИТОРИЙ
```

### 2. Установка зависимостей
> **Важное замечание для пользователей Windows:**  
> Если стандартная команда `python` перехватывается заглушкой Microsoft Store (терминал просто выводит строку `Python` или выдает ошибку командлета), запускайте команды через системный лаунчер **`py`**.

Установите библиотеки из файла спецификаций:
```bash
py -m pip install -r requirements.txt
```
*(Если переменные среды настроены корректно, доступен альтернативный вызов: `python -m pip install -r requirements.txt`)*

### 3. Проверка медиаресурсов
Убедитесь, что в корневой папке проекта лежат обязательные ресурсы:
- `delete.wav` — аудиодорожка для звукового сопровождения удаления;
- `default_cover.jpg` — базовое изображение-заглушка для книг без прикрепленной обложки.
Эти ресурсы можете заменить на другие по вашему желанию, главное удалить исходные и подписать так  же с таким же форматом.

### 4. Запуск приложения
Запустите входную точку программы:
```bash
py main.py
```
*(Либо `python main.py`)*

## Сборка Standalone версии (.exe)

Для сборки автономного приложения, не требующего установленного интерпретатора Python на проверяющем компьютере, используется утилита `PyInstaller`.

### 1. Установка сборщика
```bash
py -m pip install pyinstaller
```

### 2. Запуск сборки дистрибутива
Сборка выполняется в каталог (`--onedir`), что гарантирует надежную работу базы данных без временных файловых блокировок Windows:
```bash
py -m PyInstaller --noconsole --onedir --clean main.py
```

### 3. Финальная комплектация релиза для сдачи
После окончания сборки:
1. Перейдите в каталог `dist/main/`.
2. Поместите в эту папку рядом с файлом `main.exe`:
   - `library.db` (файл базы данных с предзаполненными данными);
   - `delete.wav` (звуковой файл);
   - `default_cover.jpg` (изображение обложки).
3. Рабочая программа запускается файлом **`main.exe`**. Для передачи на проверку достаточно заархивировать папку `main` в формат ZIP.

## Управление событиями (Events)

- **Мышь (Mouse Events):** Двойной щелчок ЛКМ по любой строке в таблице мгновенно открывает окно редактирования выбранной книги.
- **Клавиатура (Key Events):** Нажатие клавиши `Delete` на клавиатуре при выделенной строке отправляет запрос на удаление записи.
- **События выделения:** При выборе строки в таблице правая панель динамически обновляет отображение обложки соответствующей книги.
